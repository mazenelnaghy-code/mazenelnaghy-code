## Featured projects

### [Dog detection and humane repeller](https://github.com/mazenelnaghy-code/dog-detection) · graduation project

A Raspberry Pi camera system that spots dogs with YOLO11n (NCNN) and drives them away with a humane
ultrasonic repeller, built to protect kindergartens and school gates from stray dogs.

- Tested on 236 Egyptian street-dog photos: dogs found rose from **69%** (original YOLOv8n prototype)
  to **97%** on PC and **96%** on the Pi export, with **4%** child false alarms.
- Web dashboard and 100+ tests. Runs in Colab, Codespaces or Docker, no hardware needed.
- [Project page](https://mazenelnaghy-code.github.io/#/projects/dog-deterrent)

**Stack:** Python · YOLO11 (Ultralytics) · NCNN · OpenCV · Raspberry Pi · Docker

### [Egypt air quality pipeline](https://github.com/mazenelnaghy-code/egypt-air-quality)

An automated data pipeline that collects hourly air quality and weather for 8 Egyptian cities, models
it into a DuckDB star schema, tests it, and publishes a live dashboard every 6 hours with GitHub Actions.
[See the live dashboard.](https://mazenelnaghy-code.github.io/egypt-air-quality/)

**Stack:** Python · SQL · DuckDB · GitHub Actions
